# Loki65 L65S PCB

![LOKI65](https://geekhack.org/index.php?action=dlattach;topic=111422.0;attach=269065;image)

The L65S is the solderable PCB for the [Loki65](https://geekhack.org/index.php?topic=111422.0) keyboard, a shape-shifting 65%!

* Keyboard Maintainer: [Gondolindrim](https://github.com/Gondolindrim)
* Hardware Supported: proprietary PCB using STM32F411C controller
* Hardware Availability: the Loki65 has not entered Group Buy as of november 2011; hence there is no public form of obtaining it.

Make example for this keyboard (after setting up your build environment):

    make loki65/l65s:default

Flashing example for this keyboard:

    make loki65/l65s:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
